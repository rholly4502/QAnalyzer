# P3.4 — Web demo memakai Core yang sama

Tujuan: buktikan Core murni bisa dipakai ulang di web. Buat Web API tipis
(yang hanya berkaitan dgn Core) + frontend base-aware (Vite base=/analyzer/,
pun relatif) sesuai arsitektur deploy rhol-ai.tech/subpath.

## Scope
- `src/QAnalyzer.Web/` — ASP.NET Core minimal API, reference `QAnalyzer.Core`.
  Endpoints:
  - `POST /api/analyze` — body {sql, profile?, enableMaxDopTransform?}
    -> AnalysisReport (diagnostics, total, hasCritical) + transformedSql (jika maxdop).
  - `GET /api/health`.
  - Serv static file hasil build frontend (wwwroot).
- `web/` — React+Vite, base `/analyzer/`, panggil `/analyzer/api/analyze`.
- Test: xunit utk controller/service logic (EndpointService murni, testable).
- Commit terpisah: Web API, lalu frontend, lalu integrasi+README.

## Aturan TDD
- Tulis test gagal dulu (service mapping+analyze), implementasi minimal, hijau.
- Core tdk diubah (kecuali ada bug nyata — hindari).
